# Inside the Game — AI Match Recaps

A small multi-agent app built for the **Microsoft x Premier League "Inside the Game" Developer Hackathon**.

It takes a **synthetic football match**, measures how dangerous every pass and dribble was using a simple **Expected Threat (xT)** model, and then uses three AI agents to explain what happened:

| Agent | Job |
|---|---|
| 🔍 **Analyst** | Reads the xT numbers and picks out the key moments of the match |
| 🎙️ **Narrator** | Turns those moments into a match recap story |
| 🎯 **Personalizer** | Rewrites the recap for the reader: **analyst mode** (tactical, data-driven) or **casual fan mode** (fun, no jargon), in **two languages** |

The match data and the xT calculations are plain Python. The AI agents only *explain* the numbers and never invent them. The agents run on **Microsoft Foundry**.

## How to run

You need **Python 3.12**. Newer versions may not work with the Azure packages used later. Run these from the project folder, in order:

```
py -3.12 -m venv .venv              # macOS/Linux: python3.12 -m venv .venv
.venv\Scripts\Activate.ps1          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python src/generate_match.py        # writes data/match.json + data/match.csv
python src/validate_match.py        # checks the data against docs/
python src/xt_model.py              # writes data/match_xt.csv, prints top events
python src/player_summary.py        # writes data/player_summaries.json
python src/run_personalizer.py      # writes data/personalized/*.json (needs .env)
python src/run_personalizer.py --verify   # re-checks them, no model calls
```

The match is generated with a fixed random seed, so you get exactly the same data every time. The data format is described in [docs/data-format.md](docs/data-format.md), and the story the match is built around is in [docs/match-story.md](docs/match-story.md).
